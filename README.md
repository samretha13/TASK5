# Team Availability Tracker

A simple full-stack dashboard application that allows teams to manage and track user availability in real time. Users can toggle availability status, and the changes are instantly updated in the database and reflected on the frontend.

---

## Features

- Display list of team members
- Toggle availability status
- Real-time UI updates
- MongoDB database integration
- REST API using Express.js
- Simple and responsive frontend

---

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose
